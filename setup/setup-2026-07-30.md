## 1. 项目概述

这是一个基于 GitHub 的知识库系统，使用 Git 进行本地开发与云端同步。目的是创建一个全面的文档系统，记录所有技术决策、安装流程和架构选择。

---

## 2. 技术栈

### 核心技术
| 类别 | 技术 | 版本/说明 |
|------|------|-----------|
| **版本控制** | Git | v2.55.0 (Windows) |
| **包管理工具** | pnpm | 推荐用于 monorepo |
| **运行时** | Node.js LTS | 最新稳定版 |
| **知识格式** | Markdown (.md) | 标准文档格式 |
| **编辑器** | Obsidian | 本地编辑，云端同步 |
| **托管服务** | GitHub Pages / CDN | 免费托管选项 |

### 可选增强功能
| 特性 | 工具 | 优势 |
|------|------|------|
| **静态站点生成器** | Docusaurus/MkDocs | 精美的文档站点 |
| **搜索** | Algolia/Fuse.js | 全文搜索 |
| **数据库** | DuckDB + duckdb-skills | 用 SQL 查询知识库 |
| **可视化** | dataviz skill | 知识图谱可视化 |
| **自动化** | workflow/cron skills | 自动备份和维护 |

## 3. 安装流程

### 步骤 1：环境检查 ✅
```bash
# 验证 E 盘是否存在且有空间
Get-PSDrive E
# 输出：E: 44.44GB 已用，192.39GB 空闲 ✓

# 验证 git 安装
git --version
# 输出：git version 2.55.0.windows.3 ✓

# 验证用户配置
git config --global user.name
git config --global user.email
```

### 步骤 2：克隆仓库 ✅
```bash
git clone https://github.com/1079161148/knowledge-front-yuying.git E:\knowledge-front-yuying
# 提示：克隆了一个空仓库（对于新项目是正常的）
```

git add .
git commit -m "自动同步：%date% %time%"
