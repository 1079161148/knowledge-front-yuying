## 1. 项目概览 {#1-项目概览}

这是一个全栈知识库项目，托管于 GitHub，并通过 Git 与本地开发环境同步。目标是构建一个全面的文档系统，记录所有技术决策、搭建流程与架构选择。

---

## 2. 技术栈 {#2-技术栈}

### 核心技术
| 类别 | 技术 | 版本 / 说明 |
|------|------|-------------|
| **版本控制** | Git | v2.55.0（Windows） |
| **包管理器** | pnpm | 推荐用于 monorepo |
| **运行时 Node.js** | LTS 版本 | 最新稳定版 |
| **知识格式** | Markdown（.md） | 文档标准格式 |
| **编辑器** | Obsidian | 本地编辑、云同步 |
| **托管** | GitHub Pages / CDN | 免费托管方案 |

### 可选增强
| 功能 | 工具 | 收益 |
|------|------|------|
| **静态站点生成器** | Docusaurus / MkDocs | 美观的文档站点 |
| **搜索** | Algolia / Fuse.js | 全文搜索 |
| **数据库** | DuckDB + duckdb-skills | 以 SQL 查询知识库 |
| **可视化** | dataviz 技能 | 知识图谱可视化 |
| **自动化** | workflow / cron 技能 | 自动备份与维护 |
